# 🏠 HomeFix — Home Service Booking System

**HomeFix** is a web-based home service booking system that helps users explore home services, view service providers, schedule bookings, and manage their bookings through a simple and user-friendly interface.

The project is developed using HTML, CSS, and JavaScript, with browser Local Storage used to store user and booking information.

## ✨ Features

* **Home Page:** Introduction to the HomeFix platform.
* **User Registration:** Create a new account.
* **User Login:** Log in using registered account details.
* **Service Selection:** Browse available home services.
* **Service Providers:** View providers for the selected service.
* **Booking System:** Select booking details and submit a service request.
* **My Bookings:** View previously created bookings.
* **Admin Dashboard:** Access administrative features for managing and viewing booking information.
* **Responsive Styling:** Clean interface designed with CSS.
* **Local Storage:** Save and retrieve application data in the browser.

## 🚀 How to Run the Project

1. Download or clone this repository.
2. Extract the project files if downloaded as a ZIP.
3. Open the `HomeFix` project folder in Visual Studio Code.
4. Open `index.html` in a browser, or use the VS Code Live Server extension.
5. Register an account and log in to explore the available features.

## 🔄 How It Works

1. The user opens the HomeFix website.
2. The user creates an account or logs in.
3. The user browses the available home services.
4. The user selects a service and views its providers.
5. The user enters the required booking details and confirms the booking.
6. The user can view their bookings on the My Bookings page.
7. The admin page provides access to the project's administrative features.

## 💾 Data Storage

This version uses the browser's **Local Storage** to store application data.

* Data is stored in the user's browser.
* Data is not automatically synchronized between different devices.
* Clearing browser storage may remove locally saved application data.

**Note:** This project is a frontend prototype and does not include a connected backend server or database.

## 🔐 Security Note

Local Storage is suitable for demonstrating basic functionality, but it is not secure for storing real user passwords or sensitive information. A production version should use a backend, a database, secure password hashing, and proper authentication and authorization.
